# BeihangUniversityData

Эта папка содержит данные от Бэйханского университета (Beihang University).

Файлы (SystemMatrix.h5, MeasurementData_*.h5) **не закоммичены** в репозиторий.
Они находятся в письме от Бэйханского университета во внутреннем датасете.

Для работы с данными переместите/распакуйте их сюда из указанного письма.
